# tcr-cliff cookbook

A guided tour of the package, from raw pairs to a worked cross-reactivity screen.
Every notebook runs **top-to-bottom, fully offline, on the bundled synthetic toy
set** using the dependency-free *fallback* embedder. Heavy steps (ESM-2 weights,
PyTorch training, network downloads) are **guarded** with availability checks, so the
notebooks never hard-fail on a minimal install - they explain what they would do and
continue.

> **The toy data is synthetic.** It is generated by
> [`src/tcr_cliff/data/toy/_generate.py`](../src/tcr_cliff/data/toy/_generate.py) purely
> to make the cookbook self-contained and reproducible offline. It is **not** a
> benchmark and must **not** be used for any scientific or performance claim. Each
> notebook contains a clearly commented **one-line switch** to real data
> (`load_vdjdb`) and to real embeddings (`backend='esm-hf'`). See
> [`../DATASETS.md`](../DATASETS.md) for the real public sources and their licenses.

## Notebooks

| # | Notebook | What you learn |
|---|----------|----------------|
| 01 | [`01_load_data.ipynb`](01_load_data.ipynb) | Load the toy pairs, inspect the canonical schema, and make a **grouped** (leakage-safe) train/val/test split. One-line switch to `load_vdjdb`. |
| 02 | [`02_embeddings.ipynb`](02_embeddings.ipynb) | Turn CDR3b / peptide / MHC sequences into a feature matrix with `build_feature_matrix`; per-field results and disk caching. One-line switch to ESM-2 (`esm-hf`). |
| 03 | [`03_mine_cliffs.ipynb`](03_mine_cliffs.ipynb) | Detect within-`k` neighbour pairs, compute `cliff_statistics`, build and draw the **cliff graph**, and line up a concrete single-residue flip family. |
| 04 | [`04_baseline_vs_cliffaware.ipynb`](04_baseline_vs_cliffaware.ipynb) | **The headline.** Train the baseline and (if torch is available) the cliff-aware model, then `compare_models` to expose the **cliff-subset performance gap**. |
| 05 | [`05_structure_fusion.ipynb`](05_structure_fusion.ipynb) | Load 12 AlphaFold/ESMFold confidence features, train the **fusion** model (if torch), and measure the **lift on cliff records** vs the baseline. |
| 06 | [`06_interpret.ipynb`](06_interpret.ipynb) | `explain_baseline` (per-field SHAP) and model-agnostic `residue_attribution`, mapped onto the MHC-I **P2 / PΩ** anchors and CDR3b. |
| 07 | [`07_usecase_bispecific_crossreactivity.ipynb`](07_usecase_bispecific_crossreactivity.ipynb) | Worked use case: enumerate a target peptide's single-residue neighbours, score them, **flag off-target cross-reactivity**, export to **NetTCR-2.0**, and mention **ANARCI/IMGT** CDR3 extraction. |

Read them in order: 01 → 07. Notebooks 04 and 05 reuse the split and config style
introduced in 01-03.

## Running

```bash
pip install -e '.[dev]'      # offline path needs no torch / esm / network
jupyter lab cookbook/        # or: jupyter notebook cookbook/
```

To run on real data instead of the toy set, uncomment the single `load_vdjdb()` line
near the top of each notebook (it downloads and caches on first use). To use real
ESM-2 embeddings, switch the embedding config to `backend='esm-hf'`.
